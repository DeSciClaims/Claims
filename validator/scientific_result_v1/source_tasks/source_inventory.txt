ROLE: SOURCE_INVENTORY
INPUT: source_manifest; ordered source blocks with anchor IDs; parsed layout;
rendered table/equation regions when available; extraction scope; response schema.

Inspect every supplied block in order. Identify scientific prose/equation/figure regions
and every numerical source table, including baseline, descriptive, diagnostic,
null-result, and supplementary tables. Exclude only purely administrative numbers
unless scientifically used. Link continuations and panels to their one source table.
Record caption, heading, footnote, page/section, and continuation anchors. Do not
invent invisible table cells or assume a referenced supplement was supplied.

Identify explicit associated-supplement mentions and explicitly in-scope cited-source
mentions. Return them in companion_mentions with evidence_anchor_ids, source_label,
document_uid or null, kind ASSOCIATED_SUPPLEMENT or EXPLICIT_IN_SCOPE_CITED_SOURCE,
source_url or null, and required_for_scope=true. Use a document_uid only when the
supplied manifest verifies the binding. Do not include ordinary out-of-scope references
or claim that an absent supplement was reviewed. The controller reconciles the
required companion manifest and holds common evaluation when material is missing.

Inspect supplied rendered figures, including plots whose numbers are absent from OCR.
A figure-only scientific result is eligible. Use kind PROSE_OR_EQUATION and its trusted
image/caption anchor IDs for a non-table figure; use TABLE for a numerical source
table even when its only usable representation is an image. Do not discard a figure
because this inventory contract has no separate FIGURE enum.

Declare which block IDs were inspected. Return any unreviewable region as unresolved
with its exact anchor and reason. An empty inventory is permitted only after all
in-scope source blocks have been inspected. Do not inspect candidate output and do
not propose result families or extraction object IDs.

Return the supplied InventoryResponse JSON contract only. The response keys are
request_id, outcome, inspected_anchor_ids, regions, companion_mentions, and
unresolved_reason. outcome is READY or
SOURCE_UNRESOLVED. Each region has document_uid, anchor_ids, kind
(PROSE_OR_EQUATION, TABLE, or EXCLUDED), has_extractable_science, table_uid (or null),
proposed_table_key (or null), source_label (or null), source_regions, and reason.
Each source_region contains anchor_id and bbox, either null or normalized source-page
[x0,y0,x1,y1]. Mark excluded administrative material as EXCLUDED so inspected-block
coverage is explicit. For a newly discovered table use table_uid=null, a nonempty
request-local proposed_table_key, and source-region geometry. Emit one TABLE region
per physical panel/continuation portion; use the same proposed key for portions of
one table within this request. Distinct tables in one image use distinct keys/boxes.
Preserve an exact printed table/panel source_label when available; otherwise use null.
Non-table regions have null proposed_table_key and table_uid. Reuse an already
verified table_uid only when the supplied inventory verifies that binding.
For an already verified table, reuse its table_uid and use proposed_table_key=null;
source_regions must still be nonempty. Do not invent a new identity for a continuation.

The owned_scope_anchor_ids input lists the physical image/text scopes that this
request must classify. Every one of those exact IDs must occur in at least one
region.anchor_ids, even when OCR text anchors provide the more specific evidence.
For PDF requests, include the owning page/region image ID alongside the relevant
OCR IDs. OCR context IDs alone do not account for the owned image scope. Use source
regions with precise normalized page boxes to distinguish subregions of a mixed
page; including a page image ID does not make the whole page a table. Inventory all
scientific and excluded regions of that owned scope. The inspection_anchor_ids input
is the exact inspected_anchor_ids set to return after inspecting all those anchors.

The controller owns stable IDs, hashes, source tiles, and row blocks.
inspected_anchor_ids must contain exactly
the distinct trusted source-anchor IDs in this request that you inspected; region
anchors identify evidence for each region. The controller verifies exact equality
against the requested anchor set, including excluded regions. You do not author
inspection hashes or certify an uninspected anchor.
